# keyword-vector-3d

入力したキーワードを言語モデルでベクトル（埋め込み）に変換し、意味の近さを 3D 空間で可視化する単一 HTML のデモです。
「LM のベクトルデータ」を初学者に説明する勉強会用に作りました。

## 使い方

1. `index.html` をブラウザで開きます。
   ローカルサーバーか GitHub Pages で開くのがおすすめです。`file://` で開くとモデルのキャッシュが効かないことがあります。
2. キーワードを入力して「追加」を押します。`、` `,` や改行で区切ると、複数まとめて追加できます。
3. 3D 上の点かキーワードのチップをクリックすると、その言葉に近い順のランキングと線が表示されます。

### 主な機能

- 「サンプルを入れる」：犬・猫・りんご・電車などを一括で追加します。
- 「すべて消す」：追加したキーワードと 3D 上の点をすべて削除します。
- しきい値スライダー：類似度がしきい値以上のペアを線で結びます。
- 類似度マトリクス：全ペアのコサイン類似度を表で表示します。
- URL 共有：キーワードは `#w=犬,猫,…` の形で URL に保存されます。

ローカルサーバーで開く例：

```sh
python3 -m http.server 8000
# http://localhost:8000/
```

## 仕組み

| 項目 | 内容 |
| --- | --- |
| 埋め込みモデル | [`Xenova/paraphrase-multilingual-MiniLM-L12-v2`](https://huggingface.co/Xenova/paraphrase-multilingual-MiniLM-L12-v2)（日本語対応・384 次元・q8 量子化） |
| 実行環境 | [Transformers.js](https://github.com/huggingface/transformers.js) v3（すべてブラウザ内で計算・API キー不要） |
| 3D 描画 | [three.js](https://threejs.org/) r160（OrbitControls / CSS2DRenderer） |
| 3D 座標 | 384 次元ベクトルを PCA で 3 次元に圧縮した近似 |
| 近さの数値 | 元の 384 次元で計算したコサイン類似度 |

## 注意

- 初回のみモデル（約 120MB）をダウンロードします。2 回目以降はブラウザのキャッシュから読み込みます。
- 動作には jsDelivr と Hugging Face へのアクセスが必要です。
- 3D の位置は近似です。正確な近さはランキングとマトリクスで確認してください。
